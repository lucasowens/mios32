Click = press/release. ⌥-click = latch (hold gestures); click again to release. Paint on: drag across the grid to tap each key once (start on an empty key = fill, on a lit key = erase). Faders: drag. Joystick: drag (springs back), click = press; Stick sets how far you drag for full throw. ≡ opens the MatriX menu, ↔ switches Port A/B. With the SEQ: ‹ = EXIT, ✓ = play/stop, A/B = plane flip / row on-off in RACK (next par / trg layer elsewhere), stick press = home. Hold Shift = the MatriX SHIFT key.
