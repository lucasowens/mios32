Every track that plays gets an instrument by itself: a drum track a kit (each drum by its name or note), a name with pad / bass / arp / lead / keys that sound, a Chord track a pad, an Arpeggiator track a pluck, a CV track (CV1–4) a mono Eurorack-style voice and its channel-16 triggers a kit — otherwise whatever fits what it plays. Pick another instrument or level per track here. CC7 / CC10 / CC74 set a track's volume / pan / filter. Stopping the SEQ silences everything.
Click = press/release. ⌥-click = latch (hold gestures); click again to release, or it lets go when the page changes (Menu + GP). Encoders: scroll or drag to turn, click to push. Keys: Space play/stop · Esc exit · M Menu (hold it + click a GP for a page) · ←→ < / > · [] datawheel · hold Shift = Matrix SHIFT. Paint (top bar): drag along the GP step keys / MatriX grid to tap each key once (start on an empty key = fill, on a lit one = erase). Windows: drag the title bar, resize from the corner, double-click a title to fit it to the screen width; Snap (top bar) lines windows up on a 20 px grid.
