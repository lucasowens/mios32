# G1.7 — LFO onto the grammar (the 3rd emission tenant; first modulation source)

**Date:** 2026-07-05 · **Follows:** G1.6 (Groove). **User steer:** picked LFO over Robotize
as the next tenant *and* as the real load test of the descriptor ("whatever's painful
licenses the descriptor lock by pull, not push"). Robotize already has the rich ROBOLOOP
page; LFO is self-contained and the first true **modulation source** in the rack (toward
MOTION).

## Why LFO stresses the grammar differently
- **Bipolar depth.** `lfo_amplitude` is 0..255, effective `= amp-128`; **128 = center = 0
  depth = pass-through.** First center-detent dial in the rack (design principle 6).
- **Ranges exceed s8.** `lfo_steps`/`lfo_amplitude` go 0..255 — the descriptor's `s8 lo/hi`
  can't hold them. v1 keeps s8 and clamps Rate to 0..127 (1..128 steps, plenty). *Friction
  logged: the descriptor lock should widen ranges to s16.*
- **Target routing.** The LFO modulates Note/Vel/Len (`enable_flags`, on note events) or a
  **free-running CC stream** (`FastCC_Event` — the classic filter sweep, gated by
  `lfo_cc!=0` + `EXTRA_CC_OFF`, NOT the CC enable bit). One `Targ` dial hides that split.
- **Waveform, not a step-shape.** Its CUSTOM surface is a **palette** (pick a shape), a
  genuinely different GP-row content than ChordMask's mask or Groove's step-toggle.

## The row (emission, fits {occ_cc, disable_mask})
`lfo_waveform` 0..25 uses bits 0..4 only → **bit 7 free** for the disable bit, exactly like
Groove. Row = `{ "LFO", EMISSION, occ_cc=LFO_WAVEFORM, disable_mask=0x80 }`. occupied =
`waveform!=0` (Off); double-tap flips bit 7 (live A/B, keeps config).

Six OPERATE dials:
| Cell | Dial | Backing | Notes |
|---|---|---|---|
| 1 | **Wave** | `lfo_waveform` (RMW keep 0x80) | headline/occupancy; 0=off; name on right screen; engage-seeds |
| 2 | **Amp** | `lfo_amplitude` bipolar | read `raw-128`, write `v+128`; deflt 0 → 128 center = pass-through |
| 3 | **Rate** | `lfo_steps` 0..127 | shown `+1` (1..128 steps/cycle); deflt 15→16 |
| 4 | **Phas** | `lfo_phase` 0..99 | shown `%` |
| 5 | **Targ** | `lfo_enable_flags` | Note/Vel/Len/CC (single-select; CC = free stream via clearing EXTRA_CC_OFF) |
| 6 | **CC#** | `lfo_cc` 0..127 | the free-stream CC number (matters when Targ=CC) |

**Engage-seed (Wave 0→on):** if amp at center, set amp to a musical depth (~+96) and seed
`enable_flags` to a known baseline (VEL on, EXTRA_CC_OFF on) so a fresh LFO is immediately
audible as tremolo — no accidental CC spam.

**CUSTOM surface = waveform palette.** A const 16-entry palette (Off, Sine/Tri/Saw,
i-variants, a spread of pulse widths). GP-n tap → set Wave to `palette[n]` (routes through
ParamWrite so it engage-seeds); the LED lights the key matching the current waveform.

**Bypass DSP guard (seq_lfo.c):** `SEQ_LFO_Event` + `FastCC_Event` early-out on
`waveform & 0x80`; `ValueGet` masks `waveform & 0x7f` (defensive). `HandleTrk` keeps running
(phase stays in sync across bypass, per its existing invariant). Stock LFO page unaffected
(it clamps waveform 0..25, never sets bit 7).

## The point of this bundle (the pull)
LFO is the **3rd tenant** to add a bespoke branch to the same three global sites
(GP-button paint, GP-row LED, right-screen readout). Three examples = the rule-of-three
that licenses extracting the CUSTOM-surface hook into the descriptor — i.e. **G2**. This
bundle should END by naming that friction concretely, not by pre-building the abstraction.

## Deferred (flag)
- s16 ranges (Rate capped at 128 steps); multi-target LFO (single-select for now); STEPS_RST
  / CC_OFFSET / CC_PPQN / ONE_SHOT / CLK_DIV (stock page keeps them); drawing a custom curve
  (palette instead).

## By-ear GO gate
Play a track → focus LFO → dial Wave (hear tremolo via the seed) → sweep Amp/Rate → set
Targ=CC + a CC# → hear a filter sweep on the synth → tap palette shapes on the GP row →
double-tap A/B. Feels like ChordMask/Echo/Groove. GO ⇒ fold to §9 + memory; then G2 is
licensed by three worked examples.
